## 3. Two-tier visual system

Full skill routing lives in `CLAUDE.md` §4. Token summary:

| | Area A — Storefront (Premium) | Area B — Admin/POS (Minimalist) |
|---|---|---|
| Feel | Curated HSL, translucent blur overlays, soft shadows | Warm monochrome, muted pastels, flat |
| Motion | Cubic-bezier micro-interactions, scroll reveals | Minimal, operational-speed only |
| Bans | Default/stock colors | Gradients, heavy shadows, excess motion |

External component libraries below are **Area A (storefront) by default**. Pulling one into Area B (admin/POS) requires stripping motion/gradients down to the minimalist tier's rules — check `CLAUDE.md` §4 before doing that.

## 4. External libraries to draw from

Both are copy-paste-into-repo libraries (not npm installs) — components land in `frontend/src/components/ui/`, get re-themed onto the CSS-var tokens in §1 (swap any hardcoded hex for `hsl(var(--...))`), and get run through `cn()` instead of their default class-merge. They both build on Tailwind + Framer Motion, which are already installed — don't add `motion` or a competing animation lib.

### Aceternity UI — https://ui.aceternity.com

Tailwind + Framer Motion, React/Next.js. Categories most relevant to Area A:

- **Backgrounds/effects:** Aurora Background, Background Beams, Wavy Background, Vortex, Sparkles, Lamp Effect, Spotlight
- **Cards:** 3D Card Effect, Card Hover Effect, Wobble Card, Card Spotlight, Focus Cards, Glare Card, Evervault Card
- **Text:** Text Generate Effect, Typewriter Effect, Flip Words, Colourful Text
- **Scroll/parallax:** Hero Parallax, Sticky Scroll Reveal, Container Scroll Animation, Macbook Scroll
- **Sections:** Bento Grid, Timeline, Tracing Beam, Infinite Moving Cards
- **Blocks:** hero sections, navbars, CTA sections, testimonials, pricing sections (shadcn-compatible)

Good fits already flagged in this codebase: Bento Grid → value-prop cards (TTP-172), Infinite Moving Cards → trusted-brands marquee (already hand-built one — check before reaching for theirs), Card Hover Effect / Focus Cards → `PartCard.jsx` grid, Hero Parallax / Text Generate Effect → landing hero.

Global Anti-Slop rule still applies: no three-equal-card rows even when using their block templates — break symmetry.

### Motion Primitives — https://motion-primitives.com/docs

Tailwind + Motion (Framer Motion), copy-paste/CLI install (`npx motion-primitives@latest add <name>`, or manual copy — same shadcn-style pattern as Aceternity). *Live doc fetch was rate-limited (HTTP 429) during research; categories below are from the library's known public component set — verify exact API against the site when you actually pull one in.*

Categories: text effects (`TextShimmer`, `TextRoll`, `TextScramble`, `TextEffect`), `AnimatedNumber`, `Morphing Dialog`, `Morphing Popover`, `Dock`, `Carousel`, `Cursor`, `Tilt`, `Spotlight`, `Progressive Blur`, `InView`, `Marquee`, `GlowEffect`, `Accordion`/`Disclosure`, `Toolbar`, `Transition Panel`.

More restrained than Aceternity — some fit Area B too if kept minimal:
- `AnimatedNumber` → KPI dashboard tiles (`Dashboard.jsx`, `Analytics.jsx`) — pairs with `kpi-dashboard-design` skill.
- `Marquee` → already have a hand-rolled trusted-brands marquee (TTP-172); compare before swapping.
- `InView` → scroll-reveal alternative/complement to existing `Reveal.jsx`, check that one first.
- `Morphing Dialog` → candidate for `PartDetailDrawer.jsx` / `Drawer.jsx` upgrade — but `Drawer.jsx` already exists, don't replace it without a reason.

## 5. Workflow when pulling a component from either library

1. Check §2 — does an equivalent already exist in this repo? If yes, extend it, don't import a duplicate.
2. Confirm tier (Area A vs B) per `CLAUDE.md` §4 Tier routing for the target page/component.
3. Copy the component in, re-theme hardcoded colors onto the `hsl(var(--token))` system in §1, replace its class-merge with `cn()`.
4. Run the page/component through the Tier-routed core skills, then the mandatory final gate (`design-taste-frontend` → `impeccable`) per `CLAUDE.md` §4 — same as any other UI change, external source doesn't skip the gate.
